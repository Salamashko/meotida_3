# Очередь изменений для HTML-инструкций (`instructions/`)

Правило владелицы (08.10.2026, `CLAUDE.md`, раздел «Инструкции и оформление», п. 4): инструкции обновляем и вносим в них
изменения **не чаще одного раза в сутки**. Весь день изменения только дописываем сюда; в первой сессии нового календарного дня,
если очередь не пуста, вносим всё одним обновлением в HTML, очищаем очередь, обновляем дату ниже и присылаем файл в бота
(нет возможности — файлом в чат сессии). Вне очереди — только по прямой команде владелицы. Новая инструкция для новой фичи
тоже идёт в суточное обновление.

Формат записи: `- ДД.ММ.ГГГГ · файл инструкции · что изменилось (одной строкой)`. Без секретов.
