# Product Context
Вкладки (по README): **Недостача** — расчёт недостачи пачек и блоков в коробе с таможни (коды из письма склада → «Инфо по марке» → «Состав марки» → «История агрегации», выделение чужих блоков, готовое письмо `.eml` для Thunderbird, до 10 сессий с поиском по коду);
**План / Факт** — сравнение двух списков кодов; остальные вкладки — см. `README.md`.
**Пакеты Балан** (`/paketbalan/`) — из кассового файла `.spr` (или архива) выбирает чеки с пакетом `24083`: строка `55` → номер документа (поз. 6) → если в документе есть строка `11`/`13` с `24083` в поз. 8, выводятся все строки документа и код (поз. 8 строки `180`), с кнопками «Копировать» ровно как в файле; сверху сводка — все строки с кодом (180) из всех загруженных файлов подряд, одна кнопка «Копировать».
