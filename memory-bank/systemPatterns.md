# System Patterns
Один файл `index.html`, без сервера и внешних зависимостей; сессии хранятся в браузере.
Отдельные страницы — тоже по одному самодостаточному файлу: `ldnr.html` (/ldnr/), `paketbalan.html` (/paketbalan/). В `paketbalan.html` встроен 7-Zip WASM (npm `7z-wasm` 1.2.0: wasm gzip+base64 в `<script id="sevenZipWasm">`, распаковка через `DecompressionStream`; блок между `<!--VENDOR:7z-->` и `<!--/VENDOR:7z-->` перегенерирует `tools/embed-7z.py`) — поэтому файл ~1 МБ; 7-Zip поднимается только при первом архиве, на каждый архив — новый экземпляр модуля.

## 2026-11-12 — модуль XC в xmlconv.html
Точечная правка текста по позициям: токенизатор строит карту элементов (path, outer/inner, атрибуты с valStart/valEnd), все правки — список {start,end,newRaw}, применяется с конца файла; структурные операции — правки по outer-границам + перечитка токенизатора. Ничего не пересобирается через DOMParser/XMLSerializer — незатронутые байты остаются как есть. ID участников ЭДО берутся только из имени файла (parseEdoName/buildEdoName). Общий редактор: карточки и «Все поля XML» правят одни оверрайды (elemId::attr).
