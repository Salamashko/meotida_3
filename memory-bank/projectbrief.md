# Project Brief — meotida_3
«МЕОТИДА · Маркировочный стол» — одностраничное приложение (`index.html`, офлайн): шесть рабочих инструментов для кодов «Честный знак» и ЭДО в общем оформлении (тёмная/светлая тема): Недостача, План/Факт, GTIN/МЦ, УКД → иУКД, СвВыбытияМАРК, ЛДНР в ЭДО без кодов. Плюс отдельные страницы: `/ldnr/`, `/paketbalan/` («Пакеты Балан» — разбор кассовых файлов `.spr`) и `/xmlconv/` («Универсальный конвертер XML» — 11 подвкладок: перенос 5 инструментов стола + УПД→иУПД, УПД→УКД, УПД→новый УПД, новый номер и дата, обмен Продавец↔Покупатель, редактор любых полей XML).
