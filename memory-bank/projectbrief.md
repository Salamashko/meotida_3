# Project Brief — meotida_3
«МЕОТИДА · Маркировочный стол» — одностраничное приложение (`index.html`, офлайн): шесть рабочих инструментов для кодов «Честный знак» и ЭДО в общем оформлении (тёмная/светлая тема): Недостача, План/Факт, GTIN/МЦ, УКД → иУКД, СвВыбытияМАРК, ЛДНР в ЭДО без кодов. Плюс отдельные страницы: `/ldnr/` и `/paketbalan/` («Пакеты Балан» — разбор кассовых файлов `.spr`).
