Архивы — встроенный 7-Zip WASM (решение: «любой формат» включая rar/7z, офлайн, без внешних CDN; цена — файл ~1 МБ); вложенные архивы до 3 уровней; из архива берутся только `*.spr`; запароленный архив → понятная ошибка.
